Mission brief

The terrain is a hidden grid of cells, each at a whole-number height level. One cell holds the treasure. Send nodes across the grid, read what they report, and find it before your rounds or energy run out.

  1. Pick how the node finds its way: a path you draw, Greedy, or Leveler.
  2. Add the information you want back (Trace, Ping, Treasure radar) and set a movement budget. Every item shows its cost.
  3. Commit, read the report, and use radar bearings to close in.
